# AgentDock

AgentDock packages applications so Coding Agents can use their capabilities in a sandbox.

## Language

**Application Sandbox Package**

A versioned bundle that describes an application capability, including an image, a CLI, a matching Skill, and validation evidence.

**Local Verified**

A validation result for a specific package and task. An independent verifier ran the real application in a local container and checked the output against an independently maintained expectation.
