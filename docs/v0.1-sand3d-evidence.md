# V0.1 Sand3D fixture evidence

Sand3D source revision is `5cdb54e4aef76377ad1a8bbc11e257eee8fc2341`.
[CLI-Anything's Codex workflow](https://github.com/HKUDS/CLI-Anything/tree/34f519533bc175d2fe287ab8316b0dd99bb9cc43/codex-skill)
was run against an archive of that revision. A fresh Codex CLI session using
`gpt-6-sol` read the upstream Build-mode instructions and generated the console
package and its initial documentation. The session reached its usage limit after
122.74 seconds, before writing the Skills. The active Codex session completed
the paired generation using the same revision's `skill_generator.py` with a
template for the fixture's one-shot command. The two checked-in copies of the
Skill are identical. The fixture replays this reviewed pair without model calls.

The Docker recipe uses Linux amd64, pinned CPython 3.11 and Blender's `bpy`
4.5.16 wheel. The runtime has no network or host mounts. Artifact validation
reads the GLB header, JSON and binary chunks, follows the default scene's plate
mesh and computes its dimensions from indexed positions and node scale. It checks for plate material between the two expected through-hole centres
and verifies that both centres are clear. The independent verifier determines
artifact validity from the GLB bytes.

```sh
image_id=$(bash fixtures/sand3d/build.sh /path/to/sand3d)
bash fixtures/sand3d/run.sh "$image_id" /path/to/new-evidence-directory
python3 -B -m unittest discover -s tests
```

The build can use a local wheel via `SAND3D_BPY_WHEEL`. It checks the same
SHA-256 that the network path requires. The cached wheel can be shared between measurement trials.

## Live checks on 2026-11-17

Docker Desktop 29.9.1 hosted a Linux amd64 container on an arm64 Mac. Scoped
approval was needed for the Docker socket. The initial runtime build stalled
while downloading the 372.8 MB Blender wheel. Parallel HTTP range requests
recovered the exact wheel and its SHA-256 matched PyPI. The first image also
needed Debian `libsm6` and `libice6` for headless Blender. Timings below use the
corrected recipe, a checksum-verified local wheel, and warm dependency layers.
