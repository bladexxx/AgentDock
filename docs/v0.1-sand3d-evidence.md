# V0.1 Sand3D fixture evidence

Sand3D source revision is `5cdb54e4aef76377ad1a8bbc11e257eee8fc2341`.
[CLI-Anything's Codex workflow](https://github.com/HKUDS/CLI-Anything/tree/34f519533bc175d2fe287ab8316b0dd99bb9cc43/codex-skill)
was run against an archive of that revision. A fresh Codex CLI session using
`gpt-6-sol` read the upstream Build-mode instructions and generated the console
package and its initial documentation. The session reached its usage limit after
122.74 seconds, before writing the Skills. The active Codex session completed
the paired generation using the same revision's `skill_generator.py` with a
template for the fixture's one-shot command. The two checked-in copies of the
Skill are identical. The fixture replays this reviewed pair without model calls.

The Docker recipe uses Linux amd64, pinned CPython 3.11 and Blender's `bpy`
4.5.16 wheel. The runtime has no network or host mounts. Artifact validation
reads the GLB header, JSON and binary chunks, follows the default scene's plate
mesh and computes its dimensions from indexed positions and node scale.
Fixture version `sand3d-bracket-2` requires a connected, closed, oriented plate
with two tunnels. A cross-section confirms the expected positions occupy
distinct enclosed cutouts. Both rays must remain clear through the full plate
thickness. The independent verifier determines artifact validity from the GLB
bytes.

```sh
image_id=$(bash fixtures/sand3d/build.sh /path/to/sand3d sand3d-build-receipt.json)
bash fixtures/sand3d/run.sh "$image_id" sand3d-build-receipt.json /path/to/new-evidence-directory
python3 -B -m unittest discover -s tests
```

The build can use a local wheel via `SAND3D_BPY_WHEEL`. It checks the same
SHA-256 that the network path requires. The cached wheel can be shared between measurement trials. The library build
uses the base image’s signed Debian snapshot from 2026-11-04 at 21:23:39 UTC.
A cold build of the system dependency stage fetched and installed all 48
packages from that snapshot. The Blender wheel download is a separate input.

Future matched Sand3D comparisons should use the same dependency stages and
platform in both arms. The archived direct recipe and frozen AgentDock recipe
share `linux/amd64` and the same Python 3.11 Bookworm Slim image digest,
`sha256:e8c69d86735f6df3efa06b324694fe51f0422785f83a3bd463052636c2421944`.
