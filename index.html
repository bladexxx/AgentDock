How it works

从应用到可信的
可复用能力。

一个任务驱动完整流程。你可以查看包如何构建、使用什么工具，以及验证器实际检查了什么。

01 / PACKAGE

封装应用能力

组合应用镜像、CLI、匹配的 Skill 和重建配方，形成可检查的 Application Sandbox Package。

02 / RUN

在本地沙箱运行

代理通过 CLI 操作真实应用。容器边界和依赖来源都被记录，便于复现构建过程。

03 / VERIFY

独立检查结果

验证器依据独立维护的预期检查真实产物；应用命令成功退出，本身并不等于验证通过。

V0.1 scope

验证结果，要能追溯到实际产物。

V0.1 聚焦可复现的本地流程：从固定来源构建容器，在隔离环境运行应用，再由独立验证器检查文件和结构化结果。包会记录镜像、工具、Skill 和验证信息。

E2E通过浏览器 CLI 执行受控网页测试，并检查报告中的用例结果。
Sand3D通过 Python API 生成支架模型，并独立检查导出的 GLB 几何。
REBUILD固定输入与来源，支持从配方重新构建并回放验证。
LOCAL ONLY当前聚焦本地验证；注册表分发和广泛应用覆盖属于后续范围。
